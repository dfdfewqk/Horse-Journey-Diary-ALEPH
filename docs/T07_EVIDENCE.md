## 카드 5A — 실제 학습 근거 5일 사후 분석 (추가 증거)

**분석 목적:** 2026-10-14~18 동안 실제로 이루어진 자격증 실기 공부의 날짜별 수행 시간을 기존 서버 실행 기록으로 분석한다. 이 분석은 **T07의 Day 버튼 저장·인증된 앱을 5일간 사용한 검증·Day 2 이후 계획 규칙 변경을 대신하지 않는다.**

### 자료 출처 및 입력 시점

- 데이터 원본: Supabase `public.t07_execution_records`와 연결된 `t07_tasks`·`t07_plans`; 조회 및 대조일 2026-10-19 (Asia/Seoul).
- 10월 14일: 실제 공부 61분. **10월 15일 10:21에 사후 입력**한 T06 유래 복사 기록. 아직 사용자 계정에 소유권 연결이 되지 않은 항목이므로 T07 인증 상태에서 14일에 사용했다는 증거로 계산하지 않는다.
- 10월 15~18일: `자격증 실기 공부`라는 시간 기준 목표에 연결된 T07 계정 소유 실행 기록이며, 해당 날짜에 서버에 저장되었다.
- 실제 활동을 기록한 것과 그 활동을 실험 관찰로 확정 저장한 것의 시각은 구분한다.

### 계산 기준

- 지표: 해당 날짜 자격증 실기 관련 **실제 수행 시간(분)**.
- 중복 처리: 동일한 작업에서 시작 시각이 같고 종료가 약 1초 차이인 10월 15일의 76분 기록 2개는 **단일 학습 세션으로 간주하여 1개(76분)만 계산**했다. DB의 원본 행은 삭제하거나 수정하지 않았다.
- 서로 다른 날의 학습은 합산하고, 기간 중 0분인 날을 임의로 만들어 넣지 않았다.

| 실제 공부일 | 사용된 학습 시간 | 서버 기록 성격 | 분석상 처리 |
|---|---:|---|---|
| 10/14 | 61분 | 다음 날 사후 입력, 계정 미연결 | 공부 활동으로 인정, 인증 사용 증거에서는 제외 |
| 10/15 | 76분 | 해당 날짜에 T07로 기록, 76분 중복 의심 2건 | 겹친 두 행 중 1건만 계산 |
| 10/16 | 61분 | 해당 날짜에 T07로 기록 | 1건 계산 |
| 10/17 | 247분 | 해당 날짜에 T07로 기록 | 1건 계산 |
| 10/18 | 113분 | 해당 날짜에 T07로 기록 | 1건 계산 |
| **합계** | **558분 (9시간 18분)** | **실제 공부일 5일** | **중복 76분 제외** |

- 총 공부 시간 손계산: **61 + 76 + 61 + 247 + 113 = 558분**.
- 5일 평균: **558 ÷ 5 = 111.6분/일** (정수 반올림 112분).
- 계정에 연결된 10/15~18일만 계산: **76 + 61 + 247 + 113 = 497분 (8시간 17분)**.
- 미조정 DB 원본을 단순 합산할 경우 10월 15일 76분 중복으로 인해 값이 부풀려진다.
